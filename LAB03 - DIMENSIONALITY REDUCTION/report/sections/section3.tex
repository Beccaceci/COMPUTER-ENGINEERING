\subsection*{Does PCA pre-processing improve the classification accuracy? Why or why not?}

No, PCA pre-processing does not improve the classification accuracy for this dataset; in fact, aggressively reducing dimensions harms it. 

This behavior highlights a fundamental difference between the two algorithms. PCA is an unsupervised technique that discards directions with the lowest overall variance. However, variance does not necessarily equate to class separability. A feature might have very little variance overall, but if that slight variance is entirely due to the difference between the "Fake" and "Genuine" classes, it is highly discriminative. By dropping these "low variance" directions, PCA is inadvertently throwing away information that LDA could have used to separate the classes. Thus, for this specific dataset, feeding the raw features directly to LDA yields the best linear separation.

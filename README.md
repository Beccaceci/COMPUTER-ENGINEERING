# Machine-Learning-Labs-2026

Machine Learning laboratory repository for the 2025/2026 academic year.

This repository contains a collection of practical laboratory exercises developed throughout a Machine Learning course.  
The labs cover the fundamental concepts of statistical pattern recognition, probabilistic modeling, dimensionality reduction, classification, and model evaluation using Python and scientific computing libraries.

Labs Overview
LAB01 — Python Numerical Libraries
Introduction to the Python scientific ecosystem:
NumPy
SciPy
Matplotlib
Vectorized computations
Matrix operations
Data visualization
LAB02 — Iris Dataset
Exploration and analysis of the Iris dataset:
Dataset loading
Data preprocessing
Statistical analysis
Visualization techniques
Basic classification concepts
LAB03 — Dimensionality Reduction
Implementation and analysis of dimensionality reduction techniques:
Principal Component Analysis (PCA)
Linear Discriminant Analysis (LDA)
Feature projection
Variance analysis
Data visualization in lower-dimensional spaces
LAB04 — Probability and Density Estimation
Introduction to probabilistic modeling:
Maximum Likelihood Estimation (MLE)
Gaussian density estimation
Empirical distributions
LAB05 — Generative Gaussian Models
Implementation of generative classifiers:
Multivariate Gaussian (MVG) Classifier
Naive Bayes Classifier
Tied Covariance MVG
Cross-validation and performance metrics
LAB06 — Bayes Risk and Model Evaluation
Evaluation of classification systems:
Confusion matrices
Optimal Bayes decisions
Effective priors and application costs
Minimum and Actual Detection Cost Function (DCF)
Bayes Error Plots
LAB07 — Logistic Regression
Implementation of discriminative linear and quadratic classifiers:
Binary logistic regression
Multiclass logistic regression
Optimization techniques
Regularization (L2 penalty)
Score calibration
Quadratic feature expansion
LAB08 — Support Vector Machines
Implementation and analysis of discriminative geometric margin models:
Linear SVM and Margin Maximization
The Kernel Trick (Polynomial and RBF kernels)
Bias trick and data centering
Hyperparameter tuning (C, gamma, degree)
Score calibration limits of SVM geometric distances
LAB09 — Gaussian Mixture Models
Advanced density estimation and generative classification using GMMs:
Expectation-Maximization (EM) algorithm
LBG algorithm for initialization
Full, Diagonal, and Tied covariance architectures
Model selection and component tuning
Deep evaluation of structural dataset characteristics (skewness, independence)

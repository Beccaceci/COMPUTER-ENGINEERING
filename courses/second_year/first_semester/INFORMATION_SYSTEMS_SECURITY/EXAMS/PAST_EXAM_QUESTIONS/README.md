# Raccolta Completa Domande e Quiz di Esame

Questo archivio contiene l'intera raccolta di materiale d'esame, domande aperte, quiz Moodle a crocette (Vero/Falso), flashcard Anki, note di simulazione e registrazioni audio/video di correzione estratti dalla chat del corso di **Sicurezza dei Sistemi Informativi** del Politecnico di Torino (Prof. Cataldo Basile).

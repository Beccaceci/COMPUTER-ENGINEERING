\chapter{Convolutional neural networks}
\label{sec:convolutional_neural_networks}

In Chapter~\ref{sec:deep_feedforward_and_backpropagation}, we established that Multi-Layer Perceptrons equipped with non-linear activation functions are universal function approximators: given sufficient neurons, they can represent any continuous manifold. Yet, in empirical computer vision, deploying dense MLPs directly onto pixel arrays yields an immediate, catastrophic failure. Fully connected networks treat each input feature independently; they possess zero awareness of geometry, spatial adjacency, or physical symmetries.

To construct visual recognition systems that generalize efficiently, machine learning must abandon unconstrained fully connected architectures and embed the physical invariances of the natural visual world directly into the network topology. This breakthrough is realized through \textbf{Convolutional Neural Networks (CNNs)}.

From Yoshua Bengio's Bayesian perspective, a convolutional network is not merely an engineering heuristic: it is a deep neural network endowed with an \textbf{infinitely strong spatial prior}. By enforcing sparse local interactions, parameter sharing across space, and translation equivariance, CNNs slash parameter counts by orders of magnitude, preserve 2D grid topology, and mirror the hierarchical visual processing discovered in the biological mammalian visual cortex by Hubel and Wiesel.

This chapter provides an exhaustive theoretical and mathematical treatment of convolutional architectures: from continuous convolutions and discrete cross-correlations, through receptive field algebra, $1 \times 1$ bottlenecks, and global average pooling, to landmark architectural evolutions (AlexNet, VGG, ResNet) and the complete taxonomy of visual tasks (classification, detection, and semantic segmentation).

\section{Failure of dense networks on vision}
\label{sec:failure_of_fc_on_images}

In biological vision and modern artificial intelligence, visual sensory inputs are fundamentally distinct from tabular database entries or isolated acoustic waveforms: an image is a continuous, high-dimensional projection of a structured three-dimensional physical environment onto a two-dimensional sensor plane. In Chapter~\ref{sec:deep_feedforward_and_backpropagation}, we proved the Universal Approximation Theorem, establishing that Multi-Layer Perceptrons (MLPs) equipped with non-linear activation functions can approximate any continuous compact mapping to arbitrary precision. However, when machine learning practitioners attempt to deploy unconstrained fully connected architectures directly onto raw visual sensory grids, the models suffer an immediate, catastrophic empirical failure.

\subsection{Image patterns and visual regularities}
\label{sec:natural_image_statistics}

To understand why dense networks fail and how we can construct architectures tailored for vision, we must first examine the nature of visual data itself. Why do photographic images possess an inherent internal structure, and why do virtually all natural images share identical low-level statistical patterns?

\paragraph{Natural images versus white noise.}
Consider an arbitrary $256 \times 256$ RGB image with 8-bit color channels. The space of all possible pixel configurations contains:
\begin{equation}
(256)^{256 \times 256 \times 3} = 256^{196,608} \approx 10^{473,000} \text{ configurations}.
\end{equation}
If pixel intensities were drawn independently from a uniform or Gaussian distribution, the resulting image would be pure white noise: an unstructured, static television hiss containing zero discernible semantic information. In contrast, the set of all possible \textbf{natural images} occupies an infinitesimal, low-dimensional manifold embedded within this unimaginably vast space. 

Natural images are non-random because they are optical projections of a \textbf{structured 3D physical universe}:
\begin{itemize}[leftmargin=*]
  \item \textbf{Continuous Physical Matter}: Solid physical objects consist of contiguous materials with uniform surface reflectance, mass, and texture.
  \item \textbf{Smooth Optical Illumination}: Environmental light sources cast smooth illumination gradients across physical surfaces rather than fluctuating arbitrarily from millimeter to millimeter.
  \item \textbf{Localized Discontinuities}: Significant variations in pixel values occur predominantly at physical object boundaries, material transitions, and occlusion silhouettes, creating sharp, localized step edges.
  \item \textbf{Perspective Projection}: The 3D geometry of space induces regular perspective transformations, straight lines, vanishing points, and depth planes onto the 2D sensor grid.
\end{itemize}

\paragraph{Inherent self-similarity and the inpainting proof.}
Because images project continuous physical scenes, they exhibit profound \textbf{statistical self-similarity}: local visual motifs, textures, and color distributions repeat continuously across the canvas. For example, a single photograph contains repeated rectangular patterns on the spokes of a wheel, rows of nearly identical windows across an architectural facade, or consistent skin tones and textural shading between a person's forehead, cheeks, and adjacent visual regions.

A decisive qualitative demonstration of this universal self-similarity is the mechanism of \textbf{patch-based inpainting} (as utilized in digital image editing and patch synthesis algorithms). If an object is excised from a scene---such as removing an eagle soaring against a sky and mountain backdrop---the resulting empty hole can be seamlessly reconstructed without relying on external databases. An algorithm can fill the void by simply sampling, copying, and blending coherent texture patches already present in other regions of the exact same image. The fact that an occluded region can be faithfully synthesized from distant patches of the same canvas proves that natural scenes possess immense internal redundancy and spatial self-similarity.

\paragraph{Universal statistical regularities of natural scenes.}
Empirical investigations into natural image statistics reveal four universal mathematical properties shared across all natural scenes:
\begin{enumerate}[leftmargin=*]
  \item \textbf{High Local Autocorrelation}: The statistical correlation between two pixels $\mathbf{I}(\mathbf{x})$ and $\mathbf{I}(\mathbf{x} + \Delta \mathbf{x})$ approaches unity as the spatial displacement $\|\Delta \mathbf{x}\|_2 \to 0$. Adjacent pixels almost always share identical color and luminance; meaningful variation is concentrated at localized boundaries.
  \item \textbf{Scale Invariance and the $1/f^2$ Power Spectrum}: Across diverse natural landscapes, the Fourier power spectral density $S(f)$ universally follows a power law:
    \begin{equation}
    S(f) \propto \frac{1}{f^{2 - \eta}}, \quad \text{with } \eta \approx 0.2.
    \label{eq:power_spectrum_law}
    \end{equation}
    This scale invariance indicates that the visual world exhibits identical statistical structure across zoom levels: low spatial frequencies (smooth surfaces) dominate the overall energy, while high spatial frequencies (edges and fine textures) form a sparse, highly informative component.
  \item \textbf{Universality of Low-Level Edge Primitives}: Across entirely unrelated visual domains---whether inspecting facial portraits, satellite topography, medical histopathology, or urban streetscapes---images are universally constructed from the same elementary visual primitives: \textbf{oriented edges, localized color transitions, and corner junctions}.
  \item \textbf{Hierarchical Compositionality and Semantic Translation Tolerance}: Natural visual semantics are formed compositionally: local pixels combine into oriented edges, edges aggregate into textures and geometric motifs, motifs assemble into object parts (such as eyes or wheels), and parts assemble into complete semantic objects. Furthermore, the semantic identity of an object is translation-tolerant: a cat remains a cat regardless of whether it appears in the upper-left corner, the center, or the lower-right corner of the canvas.
\end{enumerate}

\paragraph{Neurobiological evidence: Hubel and Wiesel.}
This hierarchical organization is not merely an engineering convenience; it mirrors biological vision. In 1959, neurophysiologists David Hubel and Torsten Wiesel~\cite{hubel1959receptive,hubel1962receptive} discovered that the mammalian primary visual cortex (area V1) is organized into a hierarchy of specialized cells:
\begin{itemize}[leftmargin=*]
  \item \textbf{Simple Cells}: Possess small, localized receptive fields that activate selectively to oriented light bars and edges at specific angles and spatial positions.
  \item \textbf{Complex Cells}: Pool the responses of multiple simple cells across a local neighborhood, maintaining orientation selectivity while achieving invariance to small spatial shifts.
\end{itemize}
This biological discovery inspired Kunihiko Fukushima's \textbf{Neocognitron} (1980)~\cite{fukushima1980neocognitron} and Yann LeCun's \textbf{LeNet} (1989)~\cite{lecun1989backpropagation}, establishing the foundation for hierarchical representation learning in artificial vision.

\subsection{Vectorization and parameter sharing failure}
\label{sec:why_mlps_fail_images}

Despite the universal regularities governing natural images, standard Multi-Layer Perceptrons fail catastrophically when applied to raw visual grids. This breakdown is driven by two foundational structural limitations: the mandatory vectorization of multidimensional inputs and the complete absence of parameter sharing.

\paragraph{The vectorization requirement and destruction of 2D spatial topology.}
To process sensory data in an MLP, each artificial neuron computes an affine inner product followed by an element-wise activation:
\begin{equation}
z = \mathbf{w}^\top \mathbf{x} + b = \sum_{k=1}^d w_k x_k + b.
\end{equation}
Because the canonical Euclidean inner product and matrix multiplication $\mathbf{W}\mathbf{x}$ are defined exclusively over one-dimensional coordinate vectors $\mathbf{x} \in \R^d$, a dense layer \textbf{cannot natively ingest multidimensional array grids}.

Consequently, any multi-channel image tensor $\mathbf{X} \in \R^{H \times W \times C}$ must undergo mandatory \textbf{vectorization (flattening)} into an unrolled 1D column vector:
\begin{equation}
\mathbf{x} = \operatorname{vec}(\mathbf{X}) \in \R^{d}, \quad \text{where } d = H \cdot W \cdot C,
\label{eq:flattening_transformation}
\end{equation}
under which each spatial coordinate $(i, j)$ in channel $c$ is mapped to a serialized linear index $k(i, j, c) = c \cdot (HW) + i \cdot W + j$.

This flattening operation irrevocably dismantles the spatial geometry of the image:
\begin{itemize}[leftmargin=*]
  \item \textbf{Metric Space Disruption}: In the native 2D continuous image plane, distance is measured by standard Euclidean distance between coordinate pairs $\mathbf{p}_1 = (i_1, j_1)$ and $\mathbf{p}_2 = (i_2, j_2)$:
    \begin{equation}
    d_{\text{spatial}}(\mathbf{p}_1, \mathbf{p}_2) = \|\mathbf{p}_1 - \mathbf{p}_2\|_2 = \sqrt{(i_1 - i_2)^2 + (j_1 - j_2)^2}.
    \end{equation}
    Pixels that are immediate vertical neighbors, such as $(i, j)$ and $(i+1, j)$, have a physical spatial distance of $1$. However, in the flattened vector $\mathbf{x}$, their serialized indices are separated by an entire row of $W$ elements: $|k_1 - k_2| = W$. Conversely, pixels at the end of one row $(i, W)$ and the beginning of the next row $(i+1, 1)$ appear adjacent in 1D index space ($|k_1 - k_2| = 1$), despite residing on opposite physical edges of the visual canvas!
  \item \textbf{Loss of Locality and Spatial Adjacency}: Natural visual semantics emerge entirely from local spatial coherence: adjacent pixels share illumination and material properties. By discarding the 2D grid, an MLP eliminates the concept of a spatial neighborhood $\mathcal{N}(i, j)$, treating a pixel's relationship with its adjacent neighbor identically to its relationship with a distant pixel hundreds of scanlines away.
  \item \textbf{The Permutation Invariance Flaw}: Because a dense weight matrix $\mathbf{W} \in \R^{M \times d}$ assigns an unconstrained independent parameter $W_{m, k}$ to every coordinate $k$, an MLP possesses \textbf{zero spatial inductive bias}. To demonstrate this formally, let $\mathbf{P}_\pi \in \{0, 1\}^{d \times d}$ be an arbitrary fixed permutation matrix that randomly shuffles the $d$ pixel indices, transforming every image into humanly unrecognizable white noise static. If we simultaneously permute the columns of the weight matrix by $\mathbf{W}' = \mathbf{W}\mathbf{P}_\pi^\top$, then for any scrambled input $\mathbf{x}' = \mathbf{P}_\pi \mathbf{x}$:
    \begin{equation}
    \mathbf{W}' \mathbf{x}' = (\mathbf{W}\mathbf{P}_\pi^\top)(\mathbf{P}_\pi \mathbf{x}) = \mathbf{W}(\mathbf{P}_\pi^\top \mathbf{P}_\pi)\mathbf{x} = \mathbf{W}\mathbf{x}.
    \end{equation}
    The MLP produces the \textit{exact same forward pre-activations, the exact same backpropagated gradients, and the exact same loss trajectory} on scrambled white noise as it does on structured natural images! An unconstrained dense network is mathematically incapable of distinguishing a photographic scene from scrambled tabular numbers.
\end{itemize}

\paragraph{Zero parameter sharing and lack of translation equivariance.}
In an unconstrained dense layer, every hidden neuron $m$ connects to every input coordinate $k = (i, j, c)$ via a dedicated weight parameter $W_{m, (i, j, c)}$:
\begin{equation}
z_m = \sum_{c=1}^C \sum_{i=1}^H \sum_{j=1}^W W_{m, (i, j, c)} X_{i, j, c} + b_m.
\label{eq:dense_coordinate_binding}
\end{equation}
This formulation introduces two fatal limitations:
\begin{itemize}[leftmargin=*]
  \item \textbf{Coordinate-Specific Parameter Binding (Zero Weight Sharing)}: In Equation~\eqref{eq:dense_coordinate_binding}, the weight $W_{m, (i, j, c)}$ is bound to the absolute spatial coordinate $(i, j)$ on the canvas. There is \textbf{zero parameter sharing}: the weight that examines coordinate $(10, 10)$ shares no algebraic relationship with the weight examining coordinate $(150, 150)$. To share parameters across spatial locations, the matrix $\mathbf{W}$ would have to be constrained to have a doubly block-circulant (or Toeplitz) structure---which unconstrained MLPs lack entirely.
  \item \textbf{Breakdown of Translation Equivariance}: Physical objects satisfy translational symmetry: an object retains its identity regardless of where it appears on the canvas. Mathematically, a representation mapping $f: \mathcal{X} \to \mathcal{H}$ is \textbf{translation-equivariant} with respect to spatial shift $T_{\mathbf{v}}$ if:
    \begin{equation}
    f(T_{\mathbf{v}}(\mathbf{X})) = T_{\mathbf{v}}(f(\mathbf{X})), \quad \forall \mathbf{v} \in \mathbb{Z}^2.
    \end{equation}
    In an MLP, because weights are rigidly tied to absolute pixel coordinates, $f(T_{\mathbf{v}}(\mathbf{x})) \ne T_{\mathbf{v}}(f(\mathbf{x}))$. If a hidden neuron learns a set of weights that detects an eye at coordinates $(10, 10)$, and in a new test image the face shifts so the eye appears at $(150, 150)$, the neuron at $(10, 10)$ fails to activate, and the neuron at $(150, 150)$ has never observed an eye during training! The network possesses zero ability to transfer learned patterns across spatial coordinates.
  \item \textbf{Exponential Sample Complexity}: Because an MLP cannot share parameters across space, it cannot generalize across translations. To learn that an object can appear anywhere on the canvas, the MLP must observe that object at \textbf{every possible spatial coordinate $(i, j)$ during training}. This multiplies the required training dataset size by a factor proportional to the spatial resolution $H \times W$, making sample-efficient visual learning impossible.
\end{itemize}

\paragraph{Catastrophic parameter explosion and generalization failure.}
The combination of all-to-all dense connectivity and zero parameter sharing inevitably triggers a catastrophic parameter explosion:
\begin{equation}
N_{\text{weights}} = d_{\text{in}} \times d_{\text{out}} = (H \cdot W \cdot C) \times M,
\end{equation}
where $M$ is the number of neurons in the first hidden layer.
\begin{itemize}[noitemsep]
  \item \textbf{Small Resolution (CIFAR-10)}: For a tiny $32 \times 32 \times 3$ thumbnail ($d = 3,072$), connecting to a hidden layer of $M = 1,024$ neurons requires $3,072 \times 1,024 \approx 3.15 \times 10^6$ parameters.
  \item \textbf{Medium Resolution ($256 \times 256 \times 3$)}: Here, $d = 196,608$. Connecting to a modest hidden layer of $M = 2,048$ neurons requires:
    \begin{equation}
    196,608 \times 2,048 = 402,653,184 \text{ parameters (over } 402 \text{ million weights!)}
    \end{equation}
    for the \textbf{first layer alone}! Storing this single weight matrix in 32-bit floating point precision consumes over $1.61\text{ GB}$ of VRAM.
  \item \textbf{High Resolution (Full HD $1080 \times 1920 \times 3$)}: $d \approx 6.22 \times 10^6$. A single hidden layer of $2,048$ neurons would require over $1.27 \times 10^{10}$ parameters (12.7 billion weights, $\sim 50\text{ GB}$ of memory).
\end{itemize}
By Vapnik-Chervonenkis (VC) generalization theory (Chapter~\ref{sec:pac_learning_theory}), the sample complexity required to prevent overfitting scales linearly with the number of free parameters ($N \propto \mathcal{O}(|\boldsymbol{\theta}|)$). Training an unconstrained model with hundreds of millions of parameters on typical dataset sizes ($N \sim 10^4$--$10^6$) guarantees catastrophic overfitting and failure to generalize.

\section{Convolution mechanics and geometry}
\label{sec:cnn_mechanics_and_geometry}

To overcome the structural collapse of dense Multi-Layer Perceptrons on visual data, machine learning must operationalize the spatial physics of natural photographic scenes. The foundational mathematical engine for this task is the convolution operator. Tracing its lineage from functional analysis and continuous differential systems to discrete tensor mechanics, convolution transforms spatial filtering into a localized, sliding affine transformation that respects the spatial metric of continuous physical space.

Unlike unconstrained matrix multiplication---which binds an independent parameter to every absolute coordinate on the canvas---a convolutional filter slides uniformly across the pixel lattice, evaluating inner products over compact receptive fields while sharing an identical kernel tensor across every spatial position. By decoupling filter parameters from image resolution, convolution guarantees translation equivariance while slashing model complexity. Furthermore, the geometric interaction between kernel size, stride, boundary zero-padding modes (valid versus same), and dilation factors dictates the spatial downsampling trajectory and governs boundary information loss across cascading layers.

\subsection{Continuous and discrete convolution}
\label{sec:convolution_mathematical_definition}

To establish the theoretical foundations of convolutional neural networks, we examine the convolution operation from a physical and mathematical perspective, tracking how its formulation adapts across dimensions and transitions from continuous functional analysis to discrete computation~\cite{goodfellow2016deep,bishop2024deep}.

\paragraph{The general concept of convolution.}
At its core, convolution is a mathematical operator that expresses the degree of overlap between two functions as one slides across the other, computing a localized, weighted moving average. To understand its physical intuition, consider tracking the position of a spacecraft using an onboard rangefinder~\cite{goodfellow2016deep}. At continuous time $t$, the sensor emits a noisy measurement $x(t)$. To obtain an accurate trajectory estimate $s(t)$, we take a running weighted average of historical readings. Because recent measurements are more reliable than older ones, we apply a weighting kernel $w(a)$, where $a \ge 0$ represents the age of the measurement. Since a measurement acquired at time $\tau \le t$ has age $a = t - \tau$, weighting each reading $x(\tau)$ by $w(t - \tau)$ and integrating over all history yields the smoothed trajectory $s(t) = \int x(\tau) w(t - \tau) \, d\tau$.

\paragraph{Continuous formulations across dimensions.}
The continuous convolution operator generalizes across spatial dimensions by extending the domain of integration:
\begin{itemize}[leftmargin=*]
  \item \textbf{One-Dimensional (1D) Convolution}: For continuous time-series or 1D signals $x, w: \R \to \R$:
    \begin{equation}
    s(t) = (x * w)(t) \triangleq \int_{-\infty}^{\infty} x(\tau) w(t - \tau) \, d\tau.
    \label{eq:continuous_1d_convolution}
    \end{equation}
    Mechanically, this operation consists of four steps: reflecting the kernel $w(-\tau)$, translating it by offset $t$ to obtain $w(t - \tau)$, computing the pointwise product $x(\tau) w(t - \tau)$, and integrating across the real line.
  \item \textbf{Two-Dimensional (2D) Convolution}: For continuous 2D planar signals (such as continuous optical wavefields or continuous image planes) $I, K: \R^2 \to \R$, integration extends across both spatial axes:
    \begin{equation}
    S(x, y) = (I * K)(x, y) \triangleq \int_{-\infty}^{\infty} \int_{-\infty}^{\infty} I(\tau_x, \tau_y) K(x - \tau_x, \, y - \tau_y) \, d\tau_x \, d\tau_y.
    \label{eq:continuous_2d_convolution}
    \end{equation}
  \item \textbf{Three-Dimensional (3D) Convolution}: For continuous volumetric signals $I, K: \R^3 \to \R$, integration extends across three continuous coordinates:
    \begin{equation}
    S(x, y, z) = (I * K)(x, y, z) \triangleq \iiint I(\tau_x, \tau_y, \tau_z) K(x - \tau_x, \, y - \tau_y, \, z - \tau_z) \, d\tau_x \, d\tau_y \, d\tau_z.
    \label{eq:continuous_3d_convolution}
    \end{equation}
    This formulation governs volumetric physical domains, such as 3D medical tomography (MRI, CT scans), volumetric point-cloud grids, or spatio-temporal video volumes where the third axis represents time.
\end{itemize}

\paragraph{The discrete formulation and deep learning cross-correlation.}
When processing digital signals on computers, continuous functions are sampled onto discrete coordinate lattices, and continuous integrals are replaced by discrete summations:
\begin{itemize}[leftmargin=*]
  \item \textbf{Discrete 1D Convolution}: For sampled 1D arrays $x, w: \mathbb{Z} \to \R$:
    \begin{equation}
    s[n] = (x * w)[n] \triangleq \sum_{\tau=-\infty}^{\infty} x[\tau] w[n - \tau].
    \label{eq:discrete_1d_convolution}
    \end{equation}
  \item \textbf{Discrete 2D Convolution}: For sampled 2D matrices $\mathbf{I} \in \R^{H \times W}$ and discrete filter kernels $\mathbf{K} \in \R^{F \times F}$:
    \begin{equation}
    S(i, j) = (\mathbf{I} * \mathbf{K})(i, j) \triangleq \sum_{m=-\infty}^{\infty} \sum_{n=-\infty}^{\infty} \mathbf{I}(m, n) \mathbf{K}(i - m, \, j - n).
    \label{eq:discrete_2d_convolution}
    \end{equation}
  \item \textbf{Discrete 2D Cross-Correlation in Deep Learning}: While formal mathematical convolution requires reflecting the kernel indices ($i - m, j - n$), modern deep learning libraries (PyTorch, TensorFlow, JAX) omit the reflection step and compute \textbf{discrete cross-correlation}:
    \begin{equation}
    S(i, j) = (\mathbf{I} \star \mathbf{K})(i, j) \triangleq \sum_{m=0}^{F-1} \sum_{n=0}^{F-1} \mathbf{I}(i + m, \, j + n) \mathbf{K}(m, n).
    \label{eq:discrete_cross_correlation}
    \end{equation}
    In classical signal processing with fixed handcrafted filters, kernel reflection is necessary to satisfy commutativity. In deep learning, however, the kernel weights $\mathbf{K}(m, n)$ are free learnable parameters initialized randomly and optimized via backpropagation. If a task requires a reflected filter, gradient descent simply learns the reflected parameter values directly:
    \begin{equation}
    \min_{\mathbf{K}} \mathcal{L}(\mathbf{I} * \mathbf{K}) \equiv \min_{\mathbf{K}'} \mathcal{L}(\mathbf{I} \star \mathbf{K}'), \quad \text{where } \mathbf{K}'(m, n) = \mathbf{K}(-m, -n).
    \end{equation}
    Omitting kernel reflection eliminates unnecessary array index flips on GPUs with zero impact on expressive capacity. Throughout machine learning, Equation~\eqref{eq:discrete_cross_correlation} is referred to interchangeably as convolution.
\end{itemize}

\subsection{Stride, padding, and layer geometry}
\label{sec:conv_layer_anatomy}

We now formalize the full multi-channel convolutional layer as deployed in modern deep networks.

\paragraph{Input and filter tensor volumes.}
In deep neural networks, activations are represented as multi-dimensional tensor volumes:
\begin{itemize}[leftmargin=*]
  \item The input is a 3D tensor volume $\mathbf{X} \in \R^{H_{\text{in}} \times W_{\text{in}} \times C_{\text{in}}}$, where $H_{\text{in}}$ and $W_{\text{in}}$ denote spatial height and width, and $C_{\text{in}}$ denotes the channel depth (e.g., $C_{\text{in}} = 3$ for RGB color images).
  \item The layer contains a bank of $C_{\text{out}}$ distinct convolutional filters.
  \item \textbf{Fundamental Depth Rule}: \textbf{Each filter kernel must span the ENTIRE depth $C_{\text{in}}$ of the input volume!} While a filter has a local spatial receptive field of size $F \times F$, its volumetric shape is:
    \begin{equation}
    \mathbf{K}^{(k)} \in \R^{F \times F \times C_{\text{in}}}, \quad \forall k \in \{1, \dots, C_{\text{out}}\}.
    \end{equation}
\end{itemize}
Each filter $\mathbf{K}^{(k)}$ computes an element-wise dot product across all $C_{\text{in}}$ channels simultaneously over a local spatial window, adds a scalar bias $b_k \in \R$, and emits a single 2D spatial activation slice $\mathbf{Y}_{:,:,k} \in \R^{H_{\text{out}} \times W_{\text{out}}}$:
\begin{equation}
\mathbf{Y}_{i, j, k} = \sum_{c=1}^{C_{\text{in}}} \sum_{m=0}^{F-1} \sum_{n=0}^{F-1} \mathbf{X}_{i+m, \, j+n, \, c} \, \mathbf{K}^{(k)}_{m, n, c} + b_k.
\label{eq:multichannel_convolution}
\end{equation}
Stacking the resulting $C_{\text{out}}$ feature slices along the depth axis yields the complete output tensor volume $\mathbf{Y} \in \R^{H_{\text{out}} \times W_{\text{out}} \times C_{\text{out}}}$.

\paragraph{Hyperparameters: Filter size, stride, and padding.}
The spatial dimensions $H_{\text{out}}$ and $W_{\text{out}}$ of the output volume are governed by three primary geometric hyperparameters:
\begin{itemize}[leftmargin=*]
  \item \textbf{Filter Size ($F$)}: The spatial extent (height and width) of the local kernel window $F \times F$ (typically odd integers: $F \in \{3, 5, 7\}$).
  \item \textbf{Stride ($S$)}: The step displacement in pixels by which the kernel advances across the input lattice. Unit stride $S = 1$ evaluates all adjacent positions; stride $S = 2$ shifts by two pixels, skipping every second position and halving spatial resolution.
  \item \textbf{Zero-Padding ($P$)}: The width of the symmetrical border of zero-valued pixels appended around the perimeter of the input feature map, controlling spatial downsampling and preventing boundary information loss.
\end{itemize}

\begin{theorem}[Universal spatial dimension formula]
Given an input spatial dimension $N_{\text{in}}$ (height or width), filter spatial size $F$, zero-padding $P$, and stride $S$, the output spatial dimension $N_{\text{out}}$ is given by:
\begin{equation}
N_{\text{out}} = \left\lfloor \frac{N_{\text{in}} - F + 2P}{S} \right\rfloor + 1.
\label{eq:spatial_dimension_formula}
\end{equation}
\end{theorem}

\noindent\textit{Example 1 (Unit stride with valid padding)}: Consider an input feature map of size $N_{\text{in}} = 7$, convolved by a filter of size $F = 3$ with unit stride $S = 1$ and no padding ($P = 0$). Evaluating Equation~\eqref{eq:spatial_dimension_formula} gives:
\begin{equation}
N_{\text{out}} = \frac{7 - 3 + 2(0)}{1} + 1 = \frac{4}{1} + 1 = 5 \implies \text{Output is } 5 \times 5.
\end{equation}

\noindent\textit{Example 2 (Spatial downsampling via strided convolution)}: Setting stride $S = 2$ on the same input ($N_{\text{in}} = 7, F = 3, P = 0$) shifts the kernel by two pixels at each step, skipping alternate coordinates:
\begin{equation}
N_{\text{out}} = \frac{7 - 3 + 2(0)}{2} + 1 = \frac{4}{2} + 1 = 3 \implies \text{Output is } 3 \times 3.
\end{equation}

\noindent\textit{Example 3 (Hyperparameter stride compatibility condition)}: If we select stride $S = 3$ with $N_{\text{in}} = 7, F = 3, P = 0$:
\begin{equation}
\frac{7 - 3 + 0}{3} + 1 = \frac{4}{3} + 1 \approx 2.33 \implies \text{Fractional! The filter does NOT tile the grid uniformly without clipping!}
\end{equation}
In well-formed convolutional designs, hyperparameters must strictly satisfy the integer divisibility condition $(N_{\text{in}} - F + 2P) \pmod S = 0$.

\noindent\textit{Example 4 (Preserving spatial dimensions via same padding)}: Without zero-padding ($P = 0$, valid padding), each convolutional layer shrinks the spatial grid by $F - 1$ pixels, causing rapid spatial collapse in deep architectures. To maintain identical input and output dimensions ($N_{\text{out}} = N_{\text{in}}$) under unit stride $S = 1$, we enforce:
\begin{equation}
N_{\text{in}} = \frac{N_{\text{in}} - F + 2P}{1} + 1 \implies 2P = F - 1 \implies P = \frac{F - 1}{2}.
\label{eq:same_padding_formula}
\end{equation}
For standard $3 \times 3$ filters ($F = 3$), setting $P = (3-1)/2 = 1$ perfectly preserves spatial resolution (``Same'' padding). For $5 \times 5$ filters ($F = 5$), setting $P = 2$ achieves the same dimensional preservation.

\paragraph{Parameter and FLOP counting.}
Let a convolutional layer process input $\mathbf{X} \in \R^{H_{\text{in}} \times W_{\text{in}} \times C_{\text{in}}}$ with $C_{\text{out}}$ filters of size $F \times F \times C_{\text{in}}$, stride $S$, and padding $P$:
\begin{itemize}[leftmargin=*]
  \item \textbf{Total Learnable Parameters}: Each filter contains $F \times F \times C_{\text{in}}$ kernel weights plus 1 scalar bias. For $C_{\text{out}}$ filters:
    \begin{equation}
    N_{\text{params}} = \left( F \times F \times C_{\text{in}} + 1 \right) \times C_{\text{out}}.
    \label{eq:conv_param_count}
    \end{equation}
    Notice that $N_{\text{params}}$ is completely independent of the input spatial resolution $H_{\text{in}}, W_{\text{in}}$.
  \item \textbf{Total Floating-Point Multiply-Accumulate Operations (FLOPs)}: Computing each scalar output activation requires $(F \times F \times C_{\text{in}})$ multiplications and additions. Emitting the full output volume $H_{\text{out}} \times W_{\text{out}} \times C_{\text{out}}$ requires:
    \begin{equation}
    N_{\text{FLOPs}} = 2 \times H_{\text{out}} \times W_{\text{out}} \times \left( F \times F \times C_{\text{in}} \right) \times C_{\text{out}}.
    \label{eq:conv_flops_count}
    \end{equation}
\end{itemize}

\noindent\textit{Example 5 (Parameter and FLOP calculation)}: Consider an input volume of size $32 \times 32 \times 3$ convolved by $C_{\text{out}} = 10$ filters of size $5 \times 5$, with stride $S = 1$ and padding $P = 2$:
\begin{itemize}[noitemsep]
  \item Spatial Output: $H_{\text{out}} = W_{\text{out}} = \frac{32 - 5 + 2(2)}{1} + 1 = 32 \implies \text{Output volume is } 32 \times 32 \times 10$.
  \item Parameters: $(5 \times 5 \times 3 + 1) \times 10 = (75 + 1) \times 10 = 760 \text{ parameters}$.
\end{itemize}
An MLP performing the identical mapping from $3,072$ inputs to $32 \times 32 \times 10 = 10,240$ outputs would require $3,072 \times 10,240 \approx 31.4 \text{ million parameters}$! Convolution achieves a \textbf{$41,000\times$ reduction in parameters} while maintaining exact translation equivariance.

While the mechanics and geometry of convolution explain how multi-channel tensors are transformed with spatial parameter sharing, a fundamental theoretical question remains: why does this specific architectural constraint succeed so profoundly in empirical vision, and how can we understand it through Bayesian and biological principles? This question motivates examining convolutional neural networks as an infinitely strong spatial prior rooted in the functional architecture of the mammalian visual cortex.

\section{CNN priors and structural design}
\label{sec:cnns_as_infinitely_strong_prior}

In the mathematical analysis of deep learning, a pervasive misconception treats convolutional networks as merely an empirical engineering heuristic---a clever computational shortcut designed to reduce parameter counts on GPUs. As Yoshua Bengio, Ian Goodfellow, and Aaron Courville established in their foundational work, convolutional networks are deeply grounded in Bayesian probability theory: a CNN is an unconstrained fully connected network upon which an \emph{infinitely strong spatial prior} has been imposed. This prior assigns absolute zero probability mass to any linear transformation that violates spatial locality or translation equivariance, permanently restricting parameter search to a low-dimensional manifold of shared local weights.

Understanding convolutional networks through this Bayesian lens clarifies both their immense empirical power and their theoretical sample complexity. In the absence of an inductive prior, an unconstrained Multi-Layer Perceptron must observe every visual object at every possible spatial coordinate on the canvas to learn translation invariance, scaling sample complexity with image resolution $\Omega(H \cdot W \cdot N_0)$. By hardcoding spatial locality and shift equivariance into the network topology, the convolutional prior slashes sample complexity to $\mathcal{O}(N_0)$.

\subsection{Sparsity, parameter sharing, and equivariance}
\label{sec:translation_equivariance_sample_complexity}

In their foundational treatise \textit{Deep Learning}, Ian Goodfellow, Yoshua Bengio, and Aaron Courville~\cite{goodfellow2016deep} establish that convolutional networks improve upon traditional dense feedforward neural architectures by operationalizing three fundamental mathematical ideas: sparse interactions (sparse connectivity), parameter sharing (tied weights), and equivariant representations.

\paragraph{Sparse interactions.}
Traditional feedforward neural network layers compute representations using unconstrained matrix multiplication:
\begin{equation}
\mathbf{y} = \sigma(\mathbf{W} \mathbf{x} + \mathbf{b}),
\end{equation}
where every individual output unit interacts with every single input unit via an independent weight parameter $W_{i, j}$. If the input has $m$ units and the output has $n$ units, the transformation requires computing and storing an $n \times m$ matrix, with computational runtime scaling as $\mathcal{O}(m \times n)$.

In stark contrast, Convolutional Neural Networks guarantee sparse interactions by restricting the filter kernel size $F$ to be orders of magnitude smaller than the input spatial dimensions ($F \ll H, W$). Rather than connecting an output unit to all $H \times W$ input pixels, each output unit connects exclusively to a local contiguous receptive field of $F \times F$ pixels (or $F$ taps in 1D), strictly restricting non-zero linear interactions to a localized band of width $F$.

Crucially, although direct connections at each individual convolutional layer are strictly sparse, units in deeper layers of a multi-layer CNN interact indirectly with a much larger portion of the input visual grid. If each layer uses a $1\text{D}$ filter of width $F$, a unit in layer $l$ observes an effective receptive field:
\begin{equation}
\text{ERF}_l = l(F - 1) + 1
\end{equation}
input units. By stacking multiple sparsely connected convolutional layers, a deep network allows high-level neurons to synthesize complex, non-local semantic relationships across the entire image canvas while keeping every individual layer's computation strictly localized and memory-efficient.

To demonstrate the profound computational advantage of sparse interactions, Goodfellow, Bengio, and Courville~\cite{goodfellow2016deep} provide a canonical quantitative benchmark: detecting edges in a digital image of size $320 \times 280$ pixels, totaling $D = 320 \times 280 = 89,600$ pixels, to produce an output feature map of equivalent dimensions ($89,600$ units).
\begin{itemize}[leftmargin=*]
  \item \textit{Dense Fully Connected Layer}:
    An unconstrained dense weight matrix $\mathbf{W} \in \R^{89,600 \times 89,600}$ requires storing:
    \begin{equation}
    |\mathbf{W}| = (320 \times 280) \times (320 \times 280) \approx 8.028 \times 10^9 \text{ parameters } (>8 \text{ billion entries}).
    \end{equation}
    In standard 32-bit floating point precision ($4$ bytes per float), storing $\mathbf{W}$ requires:
    \begin{equation}
    8.028 \times 10^9 \times 4\text{ bytes} \approx 32.11 \times 10^9\text{ bytes} \approx 32.1\text{ GB of RAM},
    \end{equation}
    just to store the parameters of a single layer, far exceeding the memory bandwidth of high-performance GPUs. Evaluating the matrix-vector multiplication requires:
    \begin{equation}
    2 \times (89,600)^2 \approx 1.606 \times 10^{10} \text{ FLOPs } (\approx 16 \text{ billion operations}).
    \end{equation}
  
  \item \textit{Convolutional Kernel Layer}:
    Performing edge detection with a compact 2-element difference kernel $\mathbf{k} = [-1, 1]^\top$ requires storing strictly:
    \begin{equation}
    |\mathbf{k}| = 2 \text{ parameters } (8\text{ bytes}).
    \end{equation}
    Evaluating the convolution across all $(320 - 1) \times 280 = 89,320$ valid output positions requires:
    \begin{equation}
    89,320 \times 2 \approx 1.786 \times 10^5 \text{ FLOPs } (\approx 2.68 \times 10^5 \text{ FLOPs including bias additions}).
    \end{equation}
\end{itemize}
Comparing the two implementations reveals that the convolutional approach is over $60,000$ times faster computationally and requires over $4$ billion times less parameter storage.

\paragraph{Parameter sharing.}
The second foundational principle articulated by Bengio is parameter sharing (also known as tied weights): using the exact same parameter value across multiple spatial positions in a network. In a conventional dense MLP, each element $W_{i, j}$ of the weight matrix is used exactly once when multiplying the $j$-th input unit to compute the $i$-th output unit. In a CNN, each element of the filter kernel $\mathbf{K} \in \R^{F \times F}$ is applied across every single receptive field throughout the entire input grid.

While parameter sharing does not change the runtime scaling of forward propagation ($\mathcal{O}(k \times n)$ operations are still performed across the spatial grid), it dramatically reduces the number of unique parameters that must be stored in memory to $\mathcal{O}(F^2 C_{\text{in}} C_{\text{out}})$, which is completely independent of the input image dimensions $H \times W$. 

Crucially, parameter sharing provides an enormous boost in statistical efficiency. In a dense MLP, a weight connecting to pixel $(10, 10)$ only learns from patterns presented at pixel $(10, 10)$ during training. If a visual feature appears at coordinate $(200, 200)$, the weights at $(10, 10)$ receive identically zero gradient feedback. In a CNN, because the filter $\mathbf{K}$ is shared across all spatial coordinates, every pixel patch across every training image contributes a gradient update to the exact same parameter tensor. If an input image contains $100 \times 100 = 10,000$ receptive fields, a single image provides $10,000$ distinct gradient signals to update $\mathbf{K}$, dramatically slashing the number of training samples required to learn robust feature detectors.

\paragraph{Equivariant representations.}
The third foundational motivation of CNNs is the emergence of equivariant representations. Formally, a mathematical mapping $f$ is equivariant to a transformation $g$ if:
\begin{equation}
f(g(x)) = g(f(x)).
\label{eq:equivariance_general_definition}
\end{equation}
Applying the transformation $g$ to the input $x$ and then evaluating $f$ produces the identical result as evaluating $f$ first and then applying $g$ to the representation.

Visual perception imposes two distinct transformation symmetries that must not be conflated:
\begin{enumerate}[leftmargin=*]
  \item \textit{Translation Invariance}: A mapping $f: \mathcal{X} \to \mathcal{Y}$ is translation-invariant under spatial shift $\mathcal{T}_{\boldsymbol{\delta}}$ if:
    \begin{equation}
    f\left( \mathcal{T}_{\boldsymbol{\delta}} \mathbf{X} \right) = f(\mathbf{X}), \quad \forall \boldsymbol{\delta} = (\Delta x, \Delta y) \in \mathbb{Z}^2.
    \label{eq:translation_invariance_math}
    \end{equation}
    Translation invariance is the mathematically required property for whole-image categorical classification: whether an object sits in the top-left or bottom-right corner of the canvas, its semantic category label (\textit{``Cat''}) must remain unchanged.
  
  \item \textit{Translation Equivariance (Covariance)}: A mapping $f: \mathcal{X} \to \mathcal{Z}$ is translation-equivariant under spatial shift $\mathcal{T}_{\boldsymbol{\delta}}$ if:
    \begin{equation}
    f\left( \mathcal{T}_{\boldsymbol{\delta}} \mathbf{X} \right) = \mathcal{T}_{\boldsymbol{\delta}} \big[ f(\mathbf{X}) \big], \quad \forall \boldsymbol{\delta} \in \mathbb{Z}^2.
    \label{eq:translation_equivariance_math}
    \end{equation}
    Translation equivariance is indispensable for internal feature representations, dense localization, and semantic segmentation: if an object moves three pixels to the right in the visual field, all extracted feature activations in the convolutional feature map must shift by exactly three pixels to preserve physical spatial geometry.
\end{enumerate}

To understand why parameter sharing and translation equivariance cannot simply be learned by dense MLPs, consider an MLP processing a flattened image vector $\mathbf{x} = \operatorname{vec}(\mathbf{X}) \in \R^{D}$ with $D = H \cdot W$. A fully connected layer computes hidden activations via an unconstrained dense weight matrix $\mathbf{W} \in \R^{D_{\text{out}} \times D}$:
\begin{equation}
h_p = \sigma\left( \sum_{i=1}^H \sum_{j=1}^W W_{p, (i, j)} X_{i, j} + b_p \right).
\label{eq:mlp_dense_coordinate_dot}
\end{equation}
Notice that every input coordinate $(i, j)$ is governed by a completely independent, decoupled parameter $W_{p, (i, j)}$.

Suppose a visual pattern $\mathcal{P}$ (such as an eye or a sharp vertical edge) is presented at spatial coordinate $(i_1, j_1)$ during training. Backpropagation calculates the gradient of the objective $\mathcal{L}$ with respect to the weights connected to that specific coordinate:
\begin{equation}
\frac{\partial \mathcal{L}}{\partial W_{p, (i_1, j_1)}} = \delta_p X_{i_1, j_1} \neq 0.
\end{equation}
However, for any other spatial coordinate $(i_2, j_2) \neq (i_1, j_1)$ where the pattern was not presented, the local input is zero or background, yielding:
\begin{equation}
\frac{\partial \mathcal{L}}{\partial W_{p, (i_2, j_2)}} = 0.
\end{equation}
The weights connected to coordinate $(i_2, j_2)$ receive identically zero gradient updates. Consequently, if the object appears at position $(i_2, j_2)$ at test time, the MLP possesses zero ability to recognize it.

To learn translation equivariance empirically, the MLP must observe every visual concept $\mathcal{P}$ instantiated at every coordinate in the spatial translation group $\mathcal{T} = \{(\Delta x, \Delta y) \mid 0 \le \Delta x < W, \, 0 \le \Delta y < H\}$. Because the cardinality of this group is $|\mathcal{T}| = H \times W$, the required training sample complexity scales as:
\begin{equation}
N_{\text{MLP}} = \Omega\left( |\mathcal{T}| \cdot N_0 \right) = \Omega\left( H \cdot W \cdot N_0 \right),
\label{eq:sample_complexity_mlp}
\end{equation}
where $N_0$ is the sample complexity required to learn the pattern at a single fixed location. For a standard $256 \times 256$ input image, $|\mathcal{T}| = 65,536$: an MLP requires up to a $65,000\times$ larger dataset purely to brute-force learn translation invariance through exhaustive spatial data augmentation.

In contrast, a Convolutional Neural Network resolves this dilemma by hardcoding translation equivariance directly into its algebraic structure through parameter sharing. Convolving input $\mathbf{X}$ with shared kernel $\mathbf{K} \in \R^{F \times F}$ guarantees commutativity with translation by algebraic identity:
\begin{equation}
\begin{aligned}
\big[ (\mathcal{T}_{\boldsymbol{\delta}} \mathbf{X}) * \mathbf{K} \big](i, j) &= \sum_{m=0}^{F-1} \sum_{n=0}^{F-1} (\mathcal{T}_{\boldsymbol{\delta}} \mathbf{X})(i+m, \, j+n) \, K_{m, n} \\
&= \sum_{m=0}^{F-1} \sum_{n=0}^{F-1} \mathbf{X}(i - \Delta x + m, \, j - \Delta y + n) \, K_{m, n} \\
&= (\mathbf{X} * \mathbf{K})(i - \Delta x, \, j - \Delta y) = \mathcal{T}_{\boldsymbol{\delta}} \big[ (\mathbf{X} * \mathbf{K}) \big](i, j).
\end{aligned}
\label{eq:equivariance_proof}
\end{equation}
Because Equation~\eqref{eq:equivariance_proof} holds for any kernel values $\mathbf{K}$, translation equivariance is strictly hardcoded prior to observing any training data. Observing a visual feature at a single location $(i_1, j_1)$ produces a gradient that updates the shared kernel $\mathbf{K}$; this single parameter update immediately generalizes detection across all $H \times W$ locations simultaneously:
\begin{equation}
N_{\text{CNN}} = \mathcal{O}(N_0).
\label{eq:sample_complexity_cnn}
\end{equation}

\paragraph{Bengio's caveat and locally connected layers.}
Goodfellow, Bengio, and Courville~\cite{goodfellow2016deep} highlight a critical architectural caveat: parameter sharing across space is beneficial if and only if the underlying data-generating distribution is spatially stationary---that is, when features useful at one location are equally useful at all other locations. While this assumption holds universally for unconstrained natural images, it is fundamentally suboptimal when images possess a fixed, canonical spatial composition.
\begin{itemize}[leftmargin=*]
  \item \textit{The Canonical Example of Aligned Faces}:
    Consider a biometric dataset of tightly cropped, pre-aligned human faces (such as LFW or CelebA). In these images, eyes are consistently positioned in the upper quadrant, noses reside in the center, and mouths are located in the lower quadrant. There is no reason to search for an eye in the bottom corner or a mouth at the top of the canvas.
  \item \textit{The Unshared Locally Connected Solution}:
    Forced weight sharing across the entire grid forces the network to compromise between detecting eyes and detecting mouths using the same shared filters. In such canonically framed domains, unshared locally connected layers (also known as tiled convolutions without weight sharing) are theoretically and empirically superior: connections remain spatially localized to $F \times F$ patches (preserving sparse interactions), but different spatial positions $(i, j)$ learn completely separate, decoupled weight matrices $\mathbf{K}_{(i, j)}$.
\end{itemize}

\subsection{Convolution as an infinitely strong prior}
\label{sec:infinitely_strong_prior_bengio}

To attain the deepest theoretical understanding of why Convolutional Neural Networks succeed---and precisely when they fail---we must examine their architecture through the lens of Bayesian probability theory and statistical learning theory. In Chapter~9.4 of \textit{Deep Learning}, Ian Goodfellow, Yoshua Bengio, and Aaron Courville~\cite{goodfellow2016deep} introduce a unifying perspective: convolution and pooling can be understood as an infinitely strong prior on the weights of an unconstrained fully connected layer.

\paragraph{Prior probability distributions in Bayesian learning.}
In Bayesian parameter estimation, a prior probability distribution $p(\boldsymbol{\theta})$ over the model parameters $\boldsymbol{\theta}$ encodes domain assumptions about parameter values before observing training data $\mathcal{D} = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$~\cite{bishop2024deep,goodfellow2016deep}. Through Bayes' rule, the posterior distribution over parameters is:
\begin{equation}
p(\boldsymbol{\theta} \mid \mathcal{D}) \propto p(\mathcal{D} \mid \boldsymbol{\theta}) \, p(\boldsymbol{\theta}) = \left[ \prod_{i=1}^N p(y_i \mid \mathbf{x}_i, \boldsymbol{\theta}) \right] p(\boldsymbol{\theta}).
\label{eq:bayesian_posterior_weights}
\end{equation}
In Maximum A Posteriori (MAP) estimation, the optimal parameter vector maximizes the log-posterior:
\begin{equation}
\boldsymbol{\theta}_{\text{MAP}} = \arg\max_{\boldsymbol{\theta}} \left[ \sum_{i=1}^N \log p(y_i \mid \mathbf{x}_i, \boldsymbol{\theta}) + \log p(\boldsymbol{\theta}) \right].
\label{eq:map_estimation_objective}
\end{equation}
Priors exist along a continuum of strength determined by their probability entropy:
\begin{itemize}[leftmargin=*]
  \item \textit{Weak Prior}: High variance and high entropy (such as a Gaussian prior $\mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$ with large $\sigma^2$), exerting minimal regularization and allowing empirical data to drive parameter values freely.
  \item \textit{Strong Prior}: Low variance and low entropy (such as a Gaussian prior with small $\sigma^2$), heavily penalizing parameters that deviate from the prior mean.
  \item \textit{Infinitely Strong Prior}: Places zero probability mass ($p(\boldsymbol{\theta}) = 0$) on certain parameter configurations, permanently forbidding them regardless of empirical evidence. It restricts the parameter space strictly to a lower-dimensional submanifold $\mathcal{M} \subset \R^P$:
    \begin{equation}
    p(\boldsymbol{\theta}) = 
    \begin{cases}
      \phi(\boldsymbol{\theta}) & \text{if } \boldsymbol{\theta} \in \mathcal{M}, \\
      0 & \text{if } \boldsymbol{\theta} \notin \mathcal{M}.
    \end{cases}
    \label{eq:infinitely_strong_prior_support}
    \end{equation}
    If $\boldsymbol{\theta} \notin \mathcal{M}$, its posterior probability $p(\boldsymbol{\theta} \mid \mathcal{D})$ remains identically zero for any dataset, even as $N \to \infty$.
\end{itemize}

\paragraph{Convolution and pooling as infinitely strong priors.}
Under Bengio's formulation, a convolutional layer can be conceptualized as a standard unconstrained fully connected layer $\mathbf{y} = \mathbf{W}\mathbf{x}$ upon which an infinitely strong spatial prior is imposed~\cite{goodfellow2016deep}. This prior asserts two structural constraints with absolute mathematical certainty:
\begin{enumerate}[leftmargin=*]
  \item \textit{Hard Receptive Field Sparsity}: A unit at spatial coordinate $(i, j)$ in layer $l$ can only interact with units in layer $l-1$ within its local spatial neighborhood $\Omega(i, j)$. For all connections outside this receptive field, the prior assigns a Dirac delta distribution centered at zero:
    \begin{equation}
    p(W_{(i, j), (i', j')}) = \delta\big( W_{(i, j), (i', j')} \big), \quad \forall (i', j') \notin \Omega(i, j),
    \label{eq:prior_sparsity_delta}
    \end{equation}
    forcing $W_{(i, j), (i', j')} \equiv 0$ strictly and eliminating all direct long-range connections.
  
  \item \textit{Strict Spatial Parameter Sharing}: The weights connecting an output unit to its receptive field must be strictly invariant to spatial translation. Defining coordinates $\mathbf{u}_1 = (i_1, j_1)$, $\mathbf{u}_2 = (i_2, j_2)$ and displacement $\boldsymbol{\Delta} = (\Delta x, \Delta y)$, weights at identical relative offsets must be identical:
    \begin{equation}
    p\big( W_{\mathbf{u}_1, \, \mathbf{u}_1 + \boldsymbol{\Delta}} - W_{\mathbf{u}_2, \, \mathbf{u}_2 + \boldsymbol{\Delta}} \big) = \delta\big( W_{\mathbf{u}_1, \, \mathbf{u}_1 + \boldsymbol{\Delta}} - W_{\mathbf{u}_2, \, \mathbf{u}_2 + \boldsymbol{\Delta}} \big).
    \label{eq:prior_weight_tying_delta}
    \end{equation}
\end{enumerate}
Together, Equations~\eqref{eq:prior_sparsity_delta} and \eqref{eq:prior_weight_tying_delta} collapse the hypothesis space from an unconstrained $D_{\text{out}} \times D_{\text{in}}$ matrix manifold down to a banded subspace of dimension $F \times F \times C_{\text{in}} \times C_{\text{out}}$.

Similarly, spatial pooling (such as max or average pooling over a window of radius $R$) acts as an infinitely strong prior asserting that the representation must be strictly invariant to small local translations:
\begin{equation}
f\left( \mathcal{T}_{\boldsymbol{\epsilon}} \mathbf{X} \right) = f(\mathbf{X}), \quad \forall \|\boldsymbol{\epsilon}\| \le R.
\label{eq:prior_pooling_invariance}
\end{equation}
This prior encodes the domain belief that the exact sub-window spatial coordinate where a feature occurs is irrelevant, prioritizing feature presence over exact coordinate localization.

\paragraph{Underfitting risk and bias-variance trade-offs.}
An infinitely strong prior is fundamentally a double-edged sword:
\begin{itemize}[leftmargin=*]
  \item \textit{When the Prior Holds (Stationary Natural Images)}:
    If the data adheres to the prior assumptions—as natural images do, with high local spatial correlations and continuous rigid translation symmetries—the prior drastically reduces estimator variance, eliminates the $\mathcal{O}(HW)$ sample complexity overhead, and prevents overfitting without introducing harmful bias.
  
  \item \textit{When the Prior Fails (Underfitting and Bias)}:
    If the true data distribution violates the prior assumptions, an infinitely strong prior results in severe, permanent underfitting due to uncorrectable inductive bias. Because the prior assigns zero probability to functions outside $\mathcal{M}$, the true data-generating function cannot be recovered even with infinite training data ($N \to \infty$).
\end{itemize}

\paragraph{Concrete failure modes.}
Several practical vision domains expose the limitations of the convolutional and pooling prior:
\begin{enumerate}[leftmargin=*]
  \item \textit{Exact Coordinate Regression}: Tasks requiring precise pixel coordinate prediction (such as facial landmark keypoint localization, bounding-box corner regression, or robotic visual servoing) are hindered by spatial pooling, which deliberately discards fine-grained spatial offsets.
  \item \textit{Non-Local Long-Range Interactions}: Convolution restricts direct connections to local $F \times F$ windows. Capturing correlations across distant corners of an image requires stacking dozens of layers to build receptive field depth, progressively diluting high-frequency details.
  \item \textit{Vision Transformers (ViTs)}: By replacing localized convolutional priors with unconstrained multi-head self-attention, ViTs impose much weaker inductive biases. While requiring substantially more training data to converge from scratch, ViTs learn flexible global dependencies that surpass the asymptotic performance ceiling of rigid local priors on web-scale datasets.
  \item \textit{Architectural Mitigations}: Convolutional architectures address these rigidities via dilated convolutions (which expand receptive fields exponentially without adding parameters or downsampling) and multi-branch modules (such as Inception, which compute multiple kernel scales in parallel).
\end{enumerate}


\section{Architectural design principles}
\label{sec:architectural_design_principles_cnns}

The realization that convolutional networks embody an infinitely strong spatial prior explains their data efficiency, but it leaves an essential engineering challenge unsolved: how should one configure individual convolutional layers into an expressive, deep visual architecture? In the early eras of deep learning, visual networks relied on wide, heterogeneous spatial filters---such as the $11 \times 11$, $7 \times 7$, and $5 \times 5$ convolutions deployed in early CNNs---to rapidly capture extended spatial context. However, large spatial kernels suffer from quadratic computational and parameter complexity ($\mathcal{O}(k^2)$), consuming massive memory and floating-point budgets while severely constraining the total depth that can be trained under practical hardware constraints.

To break past these computational barriers, modern computer vision underwent a structural paradigm shift toward disciplined micro-architectural design principles. Rather than relying on single monolithic convolutions, contemporary deep backbones decompose spatial transformations into cascaded sequences of localized $3 \times 3$ filters. This structural decomposition achieves identical or superior effective receptive fields while dramatically slashing weight counts and introducing multiple non-linear activations that geometrically fold and partition the representation space. Combined with spatial pooling operations for progressive spatial downsampling and dense classification heads for global relational synthesis, these principles establish the canonical blueprint of modern vision architectures.

\subsection{Receptive fields and depth}
\label{sec:vgg_principle_stacking_small_kernels}

Having formalized the output geometry of individual convolutional layers, we analyze a decisive architectural paradigm shift in deep learning: \textit{should deep networks employ large convolutional kernels, or should they cascade multiple small $3 \times 3$ filters?}~\cite{simonyan2014very,bishop2024deep}

\paragraph{Receptive field arithmetic and hyperparameter selection.}
The receptive field $R_l$ of a neuron in layer $l$ is defined as the spatial extent (diameter along one axis) in the input image $\mathbf{X}^{(0)}$ that contributes to the activation of that neuron~\cite{bishop2024deep,prince2023understanding}. Let $k_l$ denote the kernel size at layer $l$, and let $s_l$ denote the layer stride. With $R_0 = 1$ (the input pixel itself), the cumulative stride (jump) preceding layer $l$ is $J_{l-1} = \prod_{i=1}^{l-1} s_i$ (with $J_0 = 1$). The effective receptive field progression follows the universal linear recurrence:
\begin{equation}
R_l = R_{l-1} + (k_l - 1) \cdot J_{l-1}.
\label{eq:receptive_field_recurrence}
\end{equation}
In standard convolutional blocks prior to pooling, the stride is unit ($s_l = 1, \forall l \implies J_{l-1} = 1$). Equation~\eqref{eq:receptive_field_recurrence} simplifies to:
\begin{equation}
R_l = R_{l-1} + (k_l - 1).
\label{eq:unit_stride_receptive_field}
\end{equation}
For a sequence of $L$ cascaded convolutional layers with identical kernel size $k$:
\begin{equation}
R_L = 1 + \sum_{l=1}^L (k - 1) = 1 + L(k - 1).
\label{eq:cascaded_receptive_field_closed_form}
\end{equation}
\textit{Example}: Specializing Equation~\eqref{eq:cascaded_receptive_field_closed_form} to standard $3 \times 3$ kernels ($k = 3 \implies k - 1 = 2$):
\begin{itemize}[leftmargin=*]
  \item \textit{Layer 1 ($L=1$)}: $R_1 = 1 + 1(2) = 3$ ($3 \times 3$ effective receptive field).
  \item \textit{Layer 2 ($L=2$)}: $R_2 = 3 + 2 = 5$ ($5 \times 5$ effective receptive field). A hidden unit $h_j^{(2)}$ at layer 2 computes a linear combination of three layer-1 units: $\{h_{j-1}^{(1)}, h_j^{(1)}, h_{j+1}^{(1)}\}$. In turn, the leftmost unit $h_{j-1}^{(1)}$ accesses input pixels $\{x_{j-2}, x_{j-1}, x_j\}$, while the rightmost unit $h_{j+1}^{(1)}$ accesses $\{x_j, x_{j+1}, x_{j+2}\}$. The total spatial span on the input is $[j-2, j+2]$, spanning $(j+2) - (j-2) + 1 = 5$ pixels along each axis. Stacking two $3 \times 3$ layers with $C$ channels requires $2 \times (3^2 C^2) = 18 C^2$ parameters compared to a single $5 \times 5$ layer requiring $1 \times (5^2 C^2) = 25 C^2$, achieving an exact parameter reduction of $\frac{25 - 18}{25} = 28\%$.
  \item \textit{Layer 3 ($L=3$)}: $R_3 = 5 + 2 = 7$ ($7 \times 7$ effective receptive field). The three layer-2 units span $[j-3, j+3]$ on the input grid, encompassing $7$ pixels along each dimension. Stacking three $3 \times 3$ layers requires $3 \times (3^2 C^2) = 27 C^2$ weights and $3 \times (2 \times 9 C^2 HW) = 54 C^2 HW$ FLOPs, compared to a single $7 \times 7$ layer requiring $1 \times (7^2 C^2) = 49 C^2$ weights and $98 C^2 HW$ FLOPs. This structural decomposition achieves an exact savings of $\frac{49 - 27}{49} \approx 45\%$ in both parameters and arithmetic operations.
\end{itemize}

This receptive field arithmetic provides the foundational guideline for selecting the architectural hyperparameters of a CNN. For a deep network to recognize semantic entities or make holistic categorical decisions, the final convolutional neurons must possess an effective receptive field that matches or exceeds the physical scale of the target objects in the input image. If an architect selects hyperparameters that produce an undersized receptive field (for instance, stacking only two convolutional layers on high-resolution $224 \times 224$ images), deep neurons remain local feature detectors blind to global spatial context. Conversely, attempting to broaden the receptive field by increasing kernel size $F$ incurs quadratic computational and storage penalties $\mathcal{O}(F^2)$. The principled hyperparameter strategy, codified by the VGG architecture~\cite{simonyan2014very}, is to fix the spatial kernel size to the minimal non-trivial odd dimension ($F = 3$) and expand the receptive field by increasing architectural depth $L$ alongside periodic spatial downsampling.

\paragraph{Non-linear vs. linear depth: Mathematical proof of collapse.}
Beyond parameter and FLOP efficiency, cascading convolutions introduces a vital question regarding representational depth: what happens if intermediate non-linear activations are omitted?

Consider a cascade of $L$ consecutive 2D convolutional layers operating without activation functions (or with identity mappings $\sigma(z) = z$):
\begin{equation}
\mathbf{Y} = \mathbf{W}_L * \big( \mathbf{W}_{L-1} * ( \dots * (\mathbf{W}_1 * \mathbf{X}) \dots ) \big).
\end{equation}
Recall that 2D continuous and discrete convolution operators are strictly associative and commutative:
\begin{equation}
\mathbf{A} * (\mathbf{B} * \mathbf{C}) = (\mathbf{A} * \mathbf{B}) * \mathbf{C}.
\end{equation}
For any two successive linear convolutional layers parameterized by kernels $\mathbf{W}_1 \in \R^{k_1 \times k_1}$ and $\mathbf{W}_2 \in \R^{k_2 \times k_2}$, the associative property yields:
\begin{equation}
\mathbf{W}_2 * (\mathbf{W}_1 * \mathbf{X}) = (\mathbf{W}_2 * \mathbf{W}_1) * \mathbf{X} = \mathbf{W}_{\text{eff}}^{(2)} * \mathbf{X},
\end{equation}
where the composite kernel $\mathbf{W}_{\text{eff}}^{(2)} = \mathbf{W}_2 * \mathbf{W}_1$ is obtained by convolving the two kernel tensors directly, spanning a spatial support of $(k_1 + k_2 - 1) \times (k_1 + k_2 - 1)$. 

By induction over $L$ successive layers, the entire multi-layer cascade algebraically collapses into a single linear convolution:
\begin{equation}
\mathbf{W}_{\text{eff}} = \mathbf{W}_L * \mathbf{W}_{L-1} * \dots * \mathbf{W}_1 \in \R^{\left(1 + \sum_{l=1}^L (k_l - 1)\right) \times \left(1 + \sum_{l=1}^L (k_l - 1)\right)},
\end{equation}
yielding the purely linear mapping:
\begin{equation}
\mathbf{Y} = \mathbf{W}_{\text{eff}} * \mathbf{X} + \mathbf{b}_{\text{eff}}.
\label{eq:linear_conv_collapse}
\end{equation}
Equation~\eqref{eq:linear_conv_collapse} proves that linear depth is an illusion: a deep stack of linear convolutions possesses no greater representational capacity than a single convolutional layer with a larger kernel size. It cannot partition input space into non-linear decision regions and merely parameterizes a low-rank, constrained factorization of a single linear filter.

To unlock the true power of architectural depth, each convolutional layer must be coupled with an element-wise non-linear activation function $\sigma(\cdot)$ (such as ReLU):
\begin{equation}
\mathbf{H}_l = \sigma\left(\mathbf{W}_l * \mathbf{H}_{l-1} + \mathbf{b}_l\right).
\end{equation}
Because non-linear activation functions do not commute with convolution ($\sigma(\mathbf{W} * \mathbf{X}) \neq \mathbf{W} * \sigma(\mathbf{X})$), each successive layer geometrically bends, folds, and partitions the representation space into an exponentially large number of linear decision regions $\mathcal{O}(2^L)$~\cite{montufar2014number,telgarsky2016benefits}. Non-linear depth allows the network to construct a true hierarchical abstraction: early layers extract elementary oriented edges, intermediate layers combine them into corners and textural primitives, and deep layers assemble complex parts and holistic object geometries.

\subsection{Pooling operations}
\label{sec:pooling_layers}

Interspersed between convolutional layers are spatial pooling (subsampling) operations. A pooling layer operates independently on each feature channel slice, replacing local spatial neighborhoods with an aggregated summary statistic~\cite{goodfellow2016deep}.

The two standard pooling operations are:
\begin{itemize}[leftmargin=*]
  \item \textit{Max Pooling}: Computes the maximum activation value within a local sliding window of spatial size $F_p \times F_p$ with stride $S_p$:
    \begin{equation}
    Y_{i, j, c} = \max_{m, n \in \{0, \dots, F_p-1\}} X_{i \cdot S_p + m, \, j \cdot S_p + n, \, c}.
    \label{eq:max_pooling_formula}
    \end{equation}
    Max pooling acts as a localized feature presence detector (a continuous logical OR): it tests whether a specific visual pattern (e.g., an edge, corner, or texture) is active anywhere within the receptive patch, regardless of its exact sub-window coordinate.
  \item \textit{Average Pooling}: Computes the arithmetic mean of activations across the window:
    \begin{equation}
    Y_{i, j, c} = \frac{1}{F_p^2} \sum_{m=0}^{F_p-1} \sum_{n=0}^{F_p-1} X_{i \cdot S_p + m, \, j \cdot S_p + n, \, c},
    \label{eq:avg_pooling_formula}
    \end{equation}
    smoothing spatial responses and capturing background feature energy.
\end{itemize}

In the framework of CNN hyperparameter selection, pooling layers serve as critical structural regulators:
\begin{itemize}[leftmargin=*]
  \item \textit{Kernel and Stride Configuration}: The canonical hyperparameter choice is an unpadded ($P=0$) non-overlapping window with $F_p = 2$ and $S_p = 2$. Setting $S_p = F_p$ ensures that every input activation belongs to exactly one pooling quadrant, preventing redundant multi-counting.
  \item \textit{Parameter-Free Computation}: Unlike convolutional layers, pooling involves fixed aggregation arithmetic and contains zero learnable parameters ($N_{\text{params}} = 0$).
  \item \textit{Spatial Downsampling and FLOP Reduction}: Halving spatial dimensions ($H_{\text{out}} = H_{\text{in}}/2$, $W_{\text{out}} = W_{\text{in}}/2$) reduces spatial activation volume by a factor of $4$ ($75\%$ area reduction). Because the computational FLOPs of subsequent convolutional layers scale as $\mathcal{O}(H \cdot W \cdot C_{\text{in}} C_{\text{out}} F^2)$, each pooling stage slashes subsequent computational and memory burdens by $75\%$.
  \item \textit{Receptive Field Doubling}: Pooling multiplies the cumulative stride of all downstream layers: $J_{\text{post}} = J_{\text{pre}} \cdot S_p$. Consequently, a subsequent $3 \times 3$ convolutional kernel jumps across twice as many input pixels, doubling its rate of receptive field expansion without increasing parameter counts.
  \item \textit{Local Translation Invariance}: If the input image shifts by one pixel, the maximum activation within a $2 \times 2$ quadrant often remains unchanged, conferring robust local shift invariance.
  \item \textit{Hyperparameter Pitfalls}: Choosing excessively large pooling kernels ($F_p > 3$) or inserting pooling stages too aggressively causes premature and irreversible loss of fine-grained spatial localization and high-frequency details.
\end{itemize}

\subsection{Building a convolutional network}
\label{sec:building_a_convolutional_network}

Designing a convolutional neural network requires synthesizing local convolutions, non-linear activations, and spatial downsampling into a coherent processing hierarchy. Rather than arranging layers arbitrarily, standard CNN architectures follow a principled modular framework structured into sequential computational stages.

\paragraph{Stage-based modular organization.}
A convolutional backbone is organized into cascading stages. Within each stage $s \in \{1, \dots, S\}$, the spatial resolution $(H_s, W_s)$ is held fixed while multiple convolutional layers extract increasingly expressive features. A complete CNN pipeline comprises:
\begin{enumerate}[leftmargin=*]
  \item \textit{Input Layer}: Ingests the raw image tensor $\mathbf{X} \in \R^{H \times W \times C_{\text{in}}}$ (e.g., $224 \times 224 \times 3$ for standard RGB images).
  \item \textit{Convolutional Stages}: A sequence of stages where each stage contains one or more convolutional layers with non-linear activations.
  \item \textit{Transition Downsampling}: Inter-stage transitions that systematically halve the spatial dimensions and expand channel capacity.
  \item \textit{Terminal Head}: A final decision module that maps the high-level spatial feature map to downstream task outputs (such as classification probabilities).
\end{enumerate}

\paragraph{Intra-stage layer design.}
Within each individual stage, the architecture adheres to the small-kernel stacking principle established by VGG:
\begin{itemize}[leftmargin=*]
  \item \textit{Filter Size ($F = 3$)}: All convolutional kernels are standardized to small $3 \times 3$ filters ($F=3$), representing the minimal footprint capable of capturing directional spatial patterns (up/down, left/right, and diagonals).
  \item \textit{Unit Stride and Same Padding ($S=1, P=1$)}: Setting stride $S = 1$ and zero-padding $P = (F-1)/2 = 1$ ensures that spatial height and width remain strictly invariant across convolutions:
    \begin{equation}
    H_{\text{out}} = \frac{H_{\text{in}} - 3 + 2(1)}{1} + 1 = H_{\text{in}}.
    \end{equation}
    This decouples feature extraction from spatial resolution reduction, allowing the network to grow deep without prematurely extinguishing spatial information.
  \item \textit{Non-Linear Activations}: Every convolutional layer is immediately followed by a non-linear activation (typically ReLU). As demonstrated in Section~\ref{sec:vgg_principle_stacking_small_kernels}, stacking $k$ non-linear $3 \times 3$ convolutions expands the receptive field to $2k + 1$ while embedding $k$ independent non-linearities, providing strictly greater representational expressiveness than a single linear filter of equivalent receptive field.
\end{itemize}

\paragraph{Inter-stage transitions: Spatial halving and channel doubling.}
Between consecutive stages, the network executes a coordinated spatial downsampling and channel expansion:
\begin{itemize}[leftmargin=*]
  \item \textit{Spatial Halving}: Spatial dimensions are halved ($H_{s+1} = H_s / 2$ and $W_{s+1} = W_s / 2$) using either max pooling ($2 \times 2, S=2$) or a strided convolution ($S=2$). This reduces the spatial area by $75\%$ ($1/4$ of the original grid cells), slashes computational FLOPs for all subsequent layers, and doubles the cumulative stride rate ($J_{s+1} = 2 J_s$), causing downstream kernels to expand their effective receptive field at twice the rate.
  \item \textit{Channel Doubling}: Concurrently with spatial halving, the number of feature channels is doubled ($C_{s+1} = 2 C_s$, e.g., $64 \to 128 \to 256 \to 512$). Because halving spatial dimensions contracts the canvas by a factor of 4, doubling the channels preserves total representational capacity while halving total activation memory:
    \begin{equation}
    \left(\frac{H_s}{2}\right) \times \left(\frac{W_s}{2}\right) \times (2 C_s) = \frac{1}{2} (H_s \times W_s \times C_s).
    \end{equation}
    As spatial coordinates become coarser, the network compensates by expanding its dictionary of semantic feature detectors, allocating greater expressive capacity to represent diverse, complex patterns.
\end{itemize}

\paragraph{Hierarchical feature abstraction.}
By combining small-kernel stacking with progressive downsampling and channel doubling, the network forms an inductive representational hierarchy:
\begin{itemize}[leftmargin=*]
  \item \textit{Shallow Layers (Stages 1--2)}: Small receptive fields and high spatial resolution capture low-level, class-agnostic geometric primitives (oriented edges, color contrasts, local gradients, simple textures).
  \item \textit{Mid-Level Layers (Stage 3)}: Moderate receptive fields aggregate primitives into structured motifs, contours, corners, and object parts (wheels, handles, organic textures).
  \item \textit{Deep Layers (Stages 4--5)}: Expansive receptive fields covering most or all of the input canvas synthesize global semantic concepts and holistic category geometries (dog faces, vehicle profiles, architectural structures).
\end{itemize}
This multi-stage pyramid of feature extraction produces a compact, semantically rich tensor $\mathbf{F} \in \R^{H' \times W' \times C'}$ (e.g., $7 \times 7 \times 512$), perfectly positioned for global decision synthesis.

This raises a fundamental architectural question: \textit{if Fully Connected Networks fail catastrophically when applied directly to images (as established in Section~\ref{sec:why_mlps_fail_images}), why is it a sound architectural design to place a Fully Connected Network at the bottom of a CNN?}

As shown in Figure~\ref{fig:end_to_end_cnn_pipeline}, placing a Fully Connected Network at the output of a convolutional backbone realizes a principled division of labor between two distinct computational regimes:
\begin{enumerate}[leftmargin=*]
  \item \textit{The Convolutional Backbone as a Geometric Feature Extractor}: The primary role of the CNN backbone is to resolve the spatial physics of natural imagery. Operating on local 2D neighborhoods via parameter sharing, it guarantees translation equivariance and builds an increasingly abstracted, multi-scale representation while progressively downsampling spatial dimensions. Each unit at coordinate $(i, j)$ in the final convolutional tensor $\mathbf{F} \in \R^{H' \times W' \times C'}$ answers a localized question: \textit{``Does semantic feature $c$ occur at spatial coordinate $(i, j)$?''}
  
  \item \textit{The Fully Connected Head as a Global Decision Synthesizer}: Whole-image classification is fundamentally a non-spatial, translation-invariant decision task: mapping input evidence to a probability distribution $\hat{\mathbf{y}} \in \Delta^{K-1}$ over $K$ categories. Recognizing a holistic category requires reasoning over the global spatial co-occurrence and relative geometric arrangement of multiple independent parts (e.g., verifying that two eyes appear above a nose, which in turn appears above a mouth). Because convolutional kernels are spatially constrained, they cannot establish unconstrained all-to-all cross-spatial correlations between distant quadrants of the canvas without an impractical number of extra layers. By flattening the feature tensor $\mathbf{v} = \operatorname{vec}(\mathbf{F}) \in \R^{H' W' C'}$, the dense head computes:
    \begin{equation}
    z_m = \sum_{c=1}^{C'} \sum_{i=1}^{H'} \sum_{j=1}^{W'} W_{m, (i, j, c)} F_{i, j, c} + b_m.
    \label{eq:dense_all_to_all_synthesis}
    \end{equation}
    Every neuron in the dense head connects to every spatial coordinate and feature channel simultaneously, enabling unconstrained relational synthesis across the entire visual field to emit categorical class logits.
\end{enumerate}

\paragraph{Parameter distribution across the architecture.}
To understand the trade-offs of this architectural composition, we must mathematically analyze where parameters are concentrated in a CNN.

While the convolutional backbone accounts for the overwhelming majority of computational FLOPs (due to sliding dot products across $H \times W$ locations), the fully connected head accounts for the vast majority of parameters. Consider the canonical benchmark of VGG-16 operating on $224 \times 224$ images:
\begin{itemize}[leftmargin=*]
  \item \textit{Convolutional Backbone Parameters}: The 13 convolutional layers (utilizing small $3 \times 3$ filters across channel depths from 64 to 512) contain a cumulative total of:
    \begin{equation}
    N_{\text{conv}} \approx 14.71 \times 10^6 \text{ parameters } (14.71\text{M}).
    \end{equation}
  \item \textit{Fully Connected Head Parameters}: The final convolutional volume of size $7 \times 7 \times 512$ is flattened into a 1D vector of dimension $d_{\text{feat}} = 7 \times 7 \times 512 = 25,088$. Connecting this vector to the first dense hidden layer of $4,096$ units requires:
    \begin{equation}
    |\mathbf{W}_{\text{fc1}}| = 25,088 \times 4,096 = 102,760,448 \text{ parameters } (\approx 102.76\text{M}).
    \end{equation}
    The second dense layer ($4,096 \to 4,096$) requires $4,096 \times 4,096 \approx 16.78\text{M}$ weights, and the final classification projection ($4,096 \to 1,000$) requires $4,096 \times 1,000 \approx 4.10\text{M}$ weights. The dense head alone totals:
    \begin{equation}
    N_{\text{fc}} = 102.76\text{M} + 16.78\text{M} + 4.10\text{M} \approx 123.64 \times 10^6 \text{ parameters } (123.64\text{M}).
    \end{equation}
\end{itemize}
Out of the total $138.36\text{M}$ parameters in VGG-16, the fully connected layers account for over $\mathbf{89.4\%}$ of all model weights, with the single transition layer ($\text{FC}_1$) alone consuming nearly $75\%$ of the network's entire parameter budget! Similarly, in AlexNet, the dense layers account for $58.6\text{M}$ out of $61.0\text{M}$ parameters ($\approx 96.1\%$). 

This mathematical derivation demonstrates that in classical CNN architectures, parameters are overwhelmingly concentrated at the dense classification head. Consequently, while the convolutional backbone provides parameter-efficient feature extraction, the dense head forms the primary bottleneck for memory storage and represents the predominant source of overfitting, necessitating heavy regularization techniques such as Dropout.

\section{Computer vision tasks}
\label{sec:downstream_cv_tasks_imagenet}

The physical visual world does not present itself as neatly isolated, canonically centered objects floating against uniform backgrounds. In real-world environments, visual scenes are continuous, highly cluttered, and composed of multiple overlapping entities distributed across complex spatial topographies. While whole-image categorical classification provides a vital mathematical benchmark for representation learning, reducing an entire high-dimensional image tensor $\mathbf{X} \in \R^{H \times W \times C}$ to a single discrete label fundamentally discards spatial coordinates, geometric dimensions, and physical relationships among visual entities. To address diverse real-world perceptual demands, machine learning formulates visual tasks along a structured spectrum of spatial granularity.

\paragraph{Image classification.}
In whole-image categorical classification, the model maps an input image $\mathbf{X} \in \R^{H \times W \times C}$ to a single categorical probability distribution $\hat{\mathbf{y}} \in \Delta^{K-1}$ over $K$ mutually exclusive classes. It answers the holistic question: \textit{``What object category is present in this image?''} Because the objective concerns only the presence of a class regardless of where it appears in the frame, image classification enforces strict \textbf{translation invariance} ($f(\mathcal{T}_{\boldsymbol{\delta}}\mathbf{X}) = f(\mathbf{X})$). While intermediate convolutional layers maintain spatial geometry through translation equivariance, the terminal classification head (via Global Average Pooling or flattening into dense layers) intentionally collapses spatial coordinates to emit invariant class predictions.

\paragraph{Object detection.}
Object detection extends visual recognition by simultaneously answering \textit{``What is present?''} and \textit{``Where is it located?''} for an arbitrary, unknown number of object instances $M \ge 0$ scattered across the canvas. Rather than predicting a single label, the model predicts a set of detections, each parameterized by a discrete categorical class $c \in \{1, \dots, K\}$ and 4D continuous bounding box coordinates $\mathbf{b} = [x_c, y_c, w, h]^\top \in \R^4$ (specifying the object's spatial centroid, width, and height). Training optimizes a composite multi-task objective combining categorical cross-entropy with continuous bounding box regression (such as Smooth $L_1$ loss). Detection performance is quantitatively evaluated using the \textbf{Intersection over Union (IoU)} metric (the ratio between the area of overlap and the area of union of predicted and ground-truth boxes), scoring detections as true positives when $\text{IoU} \ge 0.5$. Object detection reconciles translation-equivariant feature extraction across the backbone with spatial coordinate regression in the detection heads.

\paragraph{Semantic segmentation.}
Semantic segmentation formulates perception as a dense, pixel-level classification problem, assigning a categorical class label to every individual coordinate $(i, j)$ in the spatial grid: $\hat{\mathbf{Y}} \in \{1, \dots, K\}^{H \times W}$. It answers: \textit{``Which semantic class does each individual pixel belong to?''} Unlike classification, semantic segmentation strictly demands \textbf{translation equivariance}: shifting an input image by $\boldsymbol{\delta}$ must shift the corresponding segmentation mask by the identical displacement. Deep segmentation architectures resolve the inherent trade-off between downsampling to capture broad semantic context (``what'') and preserving high-resolution spatial details for boundary localization (``where'') by deploying encoder-decoder architectures (such as U-Net) equipped with skip connections that route pristine, early-stage edge features directly to the decoding layers. Importantly, semantic segmentation does not distinguish between distinct instances of the same category; all pixels belonging to the same semantic class share an identical label.

\paragraph{Instance segmentation.}
Instance segmentation synthesizes the complementary strengths of object detection and semantic segmentation. It simultaneously identifies individual object instances and predicts a detailed, pixel-level binary mask for each detected instance. While semantic segmentation labels all contiguous pixels of a given category identically, instance segmentation separates and delineates multiple overlapping or adjacent instances of the same class (e.g., distinguishing five individual sheep grazing together in a field), providing both instance-level localization and precise boundary contours.
